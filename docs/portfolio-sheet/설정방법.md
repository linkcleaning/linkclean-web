# 청소사례(말보다 결과로) 구글 시트로 직접 관리하기

홈페이지의 **"말보다 결과로 보여드리겠습니다"** 전/후 사진과 **청소사례 페이지**를
구글 시트에서 직접 고칠 수 있게 하는 설정입니다. 한 번만 설정하면, 이후에는 시트만 고치면
몇 분 안에 홈페이지에 반영됩니다.

> ⚠️ 예약 문자용 시트(`링크클린 예약`)와는 **꼭 다른 새 시트**로 만드세요.
> 이 시트는 "웹에 게시"해서 누구나 볼 수 있게 되므로, 손님 연락처가 있는 시트와 섞이면 안 됩니다.

---

## 1단계. 시트 만들기 (3분)

1. https://sheets.new 에서 새 시트를 만들고 이름을 `링크클린 청소사례`로 바꿉니다.
2. 아래쪽 탭 이름을 `청소사례`로 바꿉니다.
3. **파일 → 가져오기 → 업로드** 에서 `청소사례_템플릿.csv` 를 올리고
   "현재 시트 바꾸기"를 선택합니다. → 지금 홈페이지에 있는 사례 9개가 그대로 들어옵니다.

## 2단계. 웹에 게시 (2분)

1. **파일 → 공유 → 웹에 게시**
2. 게시할 대상: **`청소사례`** 탭 (전체 문서 X)
3. 형식: **쉼표로 구분된 값(.csv)**
4. **게시** → 나오는 주소(`https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&output=csv`)를 복사
5. 이 주소를 Claude에게 보내주시면 홈페이지에 연결해 드립니다.

---

## 시트 칸 설명

| 칸 | 내용 | 예시 |
|---|---|---|
| 공개 | `O` 보이기 / `X` 숨기기 | O |
| 분류 | 주방·욕실·화장실·곰팡이·거실·유리창·베란다·상가·쓰레기집·기타 중 하나 | 욕실 |
| 제목 | 사례 제목 | [제주시 노형동] 32평 욕실 곰팡이 제거 |
| 지역 | 작업 지역 | 제주시 노형동 |
| 전_사진 | 청소 **전** 사진 주소 | (아래 참고) |
| 후_사진 | 청소 **후** 사진 주소 (필수) | (아래 참고) |
| 설명 | 작업 내용 설명 | 실리콘 재시공 및 줄눈 살균… |
| 날짜 | 작업 날짜 | 2026-10-07 |

- **위에 있는 줄부터** 홈페이지에 먼저 나옵니다. 새 사례는 2번째 줄(제목 줄 바로 아래)에 **행 삽입**해서 넣으세요.
- 홈 화면의 큰 전/후 비교에는 분류별로 **가장 위에 있는 사례**가 나옵니다.
- 제목이나 후_사진이 비어 있는 줄은 표시되지 않습니다.

## 사진 넣는 방법 (구글 드라이브)

1. 구글 드라이브에 `청소사례 사진` 폴더를 만들고 사진을 올립니다.
2. 폴더(또는 사진)를 오른쪽 클릭 → **공유** → 일반 액세스: **링크가 있는 모든 사용자** → 완료
3. 사진 하나를 오른쪽 클릭 → **공유 → 링크 복사**
4. 복사한 주소(`https://drive.google.com/file/d/…/view?usp=sharing`)를 시트의 `전_사진` / `후_사진` 칸에 그대로 붙여넣기
   → 홈페이지가 알아서 이미지 주소로 바꿔서 보여줍니다.

> 팁: 휴대폰 사진은 용량이 크니, 가능하면 가로 1600px 정도로 줄여서 올리면 홈페이지가 빨리 뜹니다.

## 반영 시간

시트를 고치고 저장하면 보통 **5분 안에** 홈페이지에 반영됩니다.
(구글의 웹 게시 갱신 주기 + 홈페이지의 2분 캐시. 바로 안 보이면 잠시 후 새로고침하세요.)
