# 예약 문자 알림 설정 방법

손님이 홈페이지에서 예약·사진 견적을 신청하면 **010-9090-0440으로 문자**가 오고,
**구글 시트에 예약 장부**가 자동으로 쌓이도록 설정합니다.

홈페이지는 서버가 없는 정적 사이트라서, 사장님 구글 계정의 **Apps Script**가 중간에서 문자를 보내는 역할을 합니다.
문자 발송은 유료 서비스 **솔라피(SOLAPI)** 를 사용합니다. (구글 시트·Apps Script는 무료)

---

## 1단계. 솔라피 준비 (10분)

1. https://solapi.com 회원가입
2. **발신번호 등록**: `010-9090-0440` 등록 (본인 휴대폰 인증)
3. **잔액 충전**: 소액 충전 (건당 요금은 솔라피 요금표 확인. 내용이 길면 장문(LMS) 요금이 적용됩니다)
4. **API Key 발급**: 콘솔 → 개발/연동 → API Key 관리 → 새 API Key 생성
   → `API Key` 와 `API Secret` 을 복사해 둡니다. (Secret은 다시 볼 수 없으니 바로 저장)

## 2단계. 구글 시트 + Apps Script 만들기 (5분)

1. https://sheets.new 에서 새 구글 시트를 만들고 이름을 `링크클린 예약`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣은 뒤 💾 저장합니다.
4. 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   | 속성 | 값 |
   |---|---|
   | `SOLAPI_API_KEY` | 복사한 API Key |
   | `SOLAPI_API_SECRET` | 복사한 API Secret |

> API Key·Secret은 홈페이지 코드가 아니라 구글 스크립트 안에만 저장되므로 외부에 노출되지 않습니다.

## 3단계. 문자 테스트 (2분)

1. 편집기 위쪽 함수 선택 칸에서 `testNotify` 를 고르고 **▶ 실행** 을 누릅니다.
2. "권한 검토" 창이 뜨면 본인 구글 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**.
   (본인이 만든 스크립트라 뜨는 일반적인 안내입니다)
3. 010-9090-0440 으로 "[링크클린 새 예약] 테스트 고객…" 문자가 오는지, 시트에 `예약접수` 탭이 생겼는지 확인합니다.
   - 문자가 안 오면 편집기 아래 **실행 로그**에 나온 오류 문구를 Claude에게 보내주세요.

## 4단계. 웹 앱으로 배포 (3분)

1. 편집기 오른쪽 위 **배포 → 새 배포**
2. ⚙️ 유형 선택 → **웹 앱**
3. 설정
   - 설명: `링크클린 예약 알림`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.
5. 이 URL을 Claude에게 보내주시면 홈페이지에 연결해 드립니다.
   (직접 하실 경우 `src/utils/notifyReservation.ts` 의 `RESERVATION_NOTIFY_URL` 에 붙여넣기)

---

## 문자 예시

```
[링크클린 새 예약]
홍길동 010-1234-5678
입주·이사청소 / 2026-10-20 10:00
주소: 제주시 노형동 OO아파트 101동
평수: 32평
요청: 베란다 곰팡이 심해요
```

## 알아두면 좋은 점

- **스크립트를 수정했다면** 배포 → 배포 관리 → ✏️ 편집 → 버전 "새 버전" → 배포 해야 반영됩니다. (URL은 그대로)
- **스팸 방지**: 1시간에 30건이 넘으면 문자를 멈춥니다. (`Code.gs` 의 `MAX_PER_HOUR` 로 조절)
- **손님이 올린 사진**은 문자에 포함되지 않고 장수만 표시됩니다. 필요하면 카톡으로 요청해 주세요.
- **솔라피 잔액이 떨어지면 문자가 오지 않습니다.** 솔라피의 잔액 부족 알림을 켜 두세요.
- 구글 시트 `처리상태` 칸에 "연락완료 / 예약확정 / 취소" 등을 적어 장부로 쓰시면 편합니다.
